# Exact feasibility for bounded complementary tasks

Synthetic offline feasibility oracle, not an agent policy or completed diversity experiment. This block specifies a finite nonpreemptive scheduling model before enumerating cases. No private data or source changes.

Agents have integer line positions, integer skill rates and explicit refused skills. Travel takes absolute distance in ticks; one agent may serve one operation at a time. An operation has a release, inclusive finish deadline, site, one or more positive integer skill demands, and predecessor operation IDs at the same site. Work duration is ceiling(units/rate). A multi-demand operation is simultaneous: distinct agents start together and all remain occupied until the slowest finishes. Sequential work uses separate predecessor-linked operations. Completed partial work remains at its site without decay. A different crew pays a fixed handoff latency after predecessor completion; the latency occupies no agent and consumes elapsed time only. This is a stored-artifact transfer model, not a paid human handoff. Its labor cost is not silently treated as measured.

Oracle agents know every operation in advance and may travel before release or before predecessors finish, after their preceding assignment ends. Travel and work cannot overlap for the same agent. No preemption, intermediate relocation benefit, duplicated service, communication loss, skill learning or invented tasks. Refusal removes an assignment from admissibility. A future decentralized experiment must not expose oracle schedules or hidden future demand to its agents.

Exact search enumerates every precedence-compatible operation ordering and every distinct eligible crew assignment. Given each order/assignment, it schedules each operation at its earliest possible start under predecessor completion/handoff, agent availability/travel and release. It searches serial schedule-generation alternatives, retaining a minimum-makespan feasible witness. For this finite model, a feasible schedule induces an operation order consistent with each agent's tasks and dependencies; shifting that schedule left in that order cannot break upper deadlines. Thus complete enumeration decides feasibility. Cyclic precedence and invalid input are rejected before search. Nodes are bounded by an explicit limit; interrupted search without a witness is unknown, never infeasible. A found witness remains feasible even if optimality is unproved. Maximum eight operations and four agents protect the bounded scope.

A separate witness validator checks exact operation coverage, distinct crew, rates/refusal, release/deadline, durations, same-agent travel/non-overlap, dependencies and handoff. Reports separate work occupancy, travel and elapsed completion. All times are integers.

Demonstration populations: two specialists with rates X2/Y0 and X0/Y2 versus two generalists with X1/Y1 each. Both have aggregate potential rate2 for each skill and equal agent count. Their sum of each agent's maximum rate differs (4 versus2): equal per-skill totals do not match simultaneous aggregate service capacity. This deliberate accounting counterexample must not be labeled a resource-matched diversity experiment. Refusal reports both potential and usable rates.

Enumerate three task types (single X, sequential X then Y, simultaneous X and Y), units2 per demand, deadlines1 through6, common sites0 or2, and handoff latency0 or3. Both teams start at0. This yields72 paired instances, with shared, specialist-only, generalist-only, neither and unknown categories. Retain witnesses and excluded instances. Add a two-job conflict example to show that individually feasible tasks need not be jointly feasible. No inferential significance tests are appropriate for this exhaustive constructed grid.
